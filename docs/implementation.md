# Implementation map

| Location                                                               | Responsibility                                                                                                                                               |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src/`                                                                 | Focused type checks, collection matcher validation and cycle traversal.                                                                                      |
| `src/conversion/`                                                      | Explicit conversions; see the public inventory in `scripts/exports.json`.                                                                                    |
| `src/util/nativeTypes.js`                                              | Optional once-only Node classifier discovery; browser code needs no static Node import.                                                                      |
| `src/util/`                                                            | Private shared helpers; no public import guarantee.                                                                                                          |
| `index.js`                                                             | Development aggregate loading canonical source through the public inventory.                                                                                 |
| `package/index.js`, `package/index.mjs`, `package/esm/`                | Generated consumer CommonJS and ESM entry points.                                                                                                            |
| `index.d.ts`                                                           | Authored public TypeScript signatures and helper types, with generated public-function comments.                                                             |
| `package/index.d.ts`, `package/index.d.mts`, `package/types/`          | Copied root declarations and generated focused-import declarations.                                                                                          |
| `scripts/exports.json`                                                 | The public function-name manifest.                                                                                                                           |
| `scripts/api.json`                                                     | Canonical purpose-first summaries, reference descriptions, tooltip boundaries, return meanings, errors and executable examples.                              |
| `scripts/README.template.md`                                           | Authored README prose, layout and usage guidance.                                                                                                            |
| `scripts/docs.js`, `scripts/readme.js`, `scripts/api-documentation.js` | Shared metadata rendering for the README, full reference, source JSDoc and declaration-overload comments.                                                    |
| `scripts/package-layout.js`, `scripts/generate-entries.js`             | Consumer metadata, file allowlist and entry/declaration/export-map generation in the staging directory.                                                      |
| `scripts/test-build.js`                                                | Isolated build-failure, rollback and complete-output regression checks.                                                                                      |
| `scripts/test-tooltips.js`                                             | TypeScript language-service checks of installed root and focused-import hovers and signature help.                                                           |
| `scripts/test-types.js`                                                | Declaration compilation and compile-and-run fixtures using the same TypeScript compiler.                                                                     |
| `scripts/test.js`                                                      | Shared runtime-test discovery and Node option forwarding for tests and coverage.                                                                             |
| `scripts/build.js`                                                     | One complete build: entry generation, internal esbuild bundling, Terser minification, format smoke checks and complete `package/` replacement with rollback. |
| `scripts/test-tree-shaking.js`                                         | Real esbuild consumer-bundle granularity checks.                                                                                                             |
| `scripts/test-artifacts.js`                                            | Bundle notices, maps, compression and CommonJS/global/AMD behaviour.                                                                                         |
| `benchmarks/cases.js`, `scripts/benchmark*.js`                         | Benchmark workloads and command-line measurement runners.                                                                                                    |
| `scripts/pack-package.js`, `scripts/verify.js`                         | Fresh package assembly, explicit packing into `artifacts/` and verification of that exact tarball.                                                           |
| `scripts/test-package.js`                                              | Clean installed-tarball, import and declaration checks without rebuilding or repacking.                                                                      |
| `test/`, `test/browser/`                                               | Public-behaviour, documentation, import, declaration and browser tests.                                                                                      |

Public functions have one implementation. Source-directory compatibility imports are export-map aliases, not separate implementations. The documentation and entry manifests are checked against the real public API.

See [project-design.md](project-design.md) for the contracts, [project-testing.md](project-testing.md) for contract test coverage, and [CONTRIBUTING.md](../CONTRIBUTING.md) for generation and release-verification commands.
